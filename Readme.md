📚 Library Management System

📌 Project Overview

The Library Management System is a Java-based application designed to demonstrate the fundamentals of Object-Oriented Programming (OOP). It provides a simple, menu-driven interface for managing book information and performing basic library operations.

This project was developed to strengthen Core Java programming skills and demonstrate practical implementation of OOP concepts.

🎯 Objectives

- Understand and implement Core Java concepts.
- Apply Object-Oriented Programming principles.
- Practice conditional statements, loops, and methods.
- Develop a menu-driven console application.
- Improve problem-solving and programming skills.

🛠️ Technologies Used

- Programming Language: Java
- Concepts: Object-Oriented Programming (OOP)
- Interface: Console-Based User Interface
- Development Environment: Any Java-compatible IDE or compiler

✨ Key Features

- Display book details.
- Menu-driven program execution.
- Simple and user-friendly console interface.
- Structured Java code.
- Demonstration of fundamental programming concepts.

Note: Features depend on the functionality implemented in the source code.

▶️ How to Run the Project

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project in a Java-compatible IDE or terminal.
4. Compile the Java source file.
5. Run the program.

Using the Terminal

If your source file is named "Main.java", execute:

javac Main.java
java Main
